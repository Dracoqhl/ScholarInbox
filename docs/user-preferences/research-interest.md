# Research Interest Profile

## Summary

The user focuses on large language models as text/code/math decision makers and complex problem solvers.

The central interest is using LLMs to solve abstract decision-making and complex reasoning problems, including Markov decision processes, partially observable decision processes, sequential decision-making, planning, search, long-horizon reasoning, coding, mathematics, formal reasoning, algorithmic reasoning, and multi-step problem solving.

The user does not currently consider multimodal, vision-language, embodied, robotics, or traditional non-LLM decision-making work relevant.

## Always Include

Include papers whose core contribution is about any of the following:

- LLM reasoning, including mathematical reasoning, coding reasoning, formal reasoning, theorem proving, algorithmic reasoning, symbolic reasoning, and multi-step reasoning.
- Test-time scaling and inference-time problem solving, including search, planning, verification, self-correction, self-reflection, tree/graph-of-thought, verifier-guided decoding, process supervision, and long-horizon reasoning.
- LLM post-training for reasoning or decision-making, including SFT, RL, RLHF, DPO, RLAIF, RLVR, outcome rewards, process rewards, reward models, verifiable rewards, preference optimization, and reasoning-oriented alignment.
- Agentic RL and training language model agents for tool use, search, code execution, environment interaction, long-horizon tasks, and complex problem solving.
- LLM agents, broadly defined, including agent architectures, memory modules, tool use, browser/search/code agents, planner-executor systems, reflection, self-improvement, workflow orchestration, multi-agent collaboration, and agent evaluation.
- LLMs applied to MDPs, POMDPs, sequential decision-making, planning, search, policy improvement, or decision processes, as long as the central method or subject is a language model.
- Benchmarks, datasets, or evaluation methods specifically for LLM reasoning, coding, math, formal reasoning, agents, tool use, long-horizon tasks, planning, search, or LLM decision-making.
- Alignment papers only when they directly concern LLM post-training, preference optimization, reward modeling, reasoning alignment, agent alignment, or improving reasoning/decision-making behavior.

## Exclude

Exclude papers whose core contribution is mainly about any of the following:

- All multimodal and vision-language work, including VLMs, multimodal LLMs, image/video-language reasoning, visual agents, GUI agents based on screenshots, embodied VLM agents, multimodal tool use, visual planning, image/video understanding, and image/video generation. Even if the paper discusses reasoning or agents, exclude it if the central model, task, or benchmark is multimodal rather than text/code/math/formal reasoning.
- Embodied AI, robotics, navigation, manipulation, autonomous driving, physical control, or sensorimotor decision-making.
- Traditional reinforcement learning, traditional planning, control theory, operations research, bandits, MDP/POMDP algorithms, or decision-making methods without a clear LLM, language-agent, or reasoning connection.
- Pure computer vision, image generation, video generation, medical imaging, remote sensing, sensors, time-series forecasting, recommendation systems, graph learning, distributed optimization, or generic machine learning, unless directly focused on text/code/math LLM reasoning, LLM agents, agentic RL, or language-model decision-making.
- Generic LLM benchmarks, datasets, or evaluations that are not specifically about reasoning, coding, math, agents, tool use, long-horizon problem solving, planning, search, or decision-making.
- Pure efficiency, compression, serving, systems, or inference acceleration papers, unless they directly enable test-time scaling, reasoning, agentic workflows, or complex problem solving by LLMs.
- Jailbreak, red-teaming, toxicity, bias, privacy, watermarking, content moderation, safety benchmark, misuse monitoring, policy compliance, or general LLM safety work, unless the core contribution directly supports post-training, reward modeling, reasoning alignment, agent alignment, or decision-making capability.
